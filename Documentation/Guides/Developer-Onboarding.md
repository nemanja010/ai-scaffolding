# Developer Onboarding & Workflow Guide

## Welcome
This repository supports collaborative engineering with AI coding assistants (GitHub Copilot, OpenCode, Claude Code, and Antigravity).

## Working with OpenSpec
1. **Propose Changes**: Use `/opsx-propose` (or `/opsx:propose`) to draft specs, designs, and tasks.
2. **Apply Changes**: Use `/opsx-apply` (or `/opsx:apply`) to implement tasks step-by-step.
3. **Verify**: Use `/opsx-verify` (or `/opsx:verify`) to validate spec and scenario coverage.
4. **Archive & Sync**: Use `/opsx-archive` to finalize the change, followed by `/opsx-sync-docs` to update this documentation vault.
